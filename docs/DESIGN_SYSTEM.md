# Sistema visual

- Bordô profundo `#5c1f30`, creme `#f7f2e8`, verde `#324738` e carvão `#251d1c`.
- Georgia nos títulos editoriais; sans-serif do sistema na interface.
- Bordas finas, pouco arredondamento, espaço generoso e movimento discreto.
- Contraste, foco visível, HTML semântico e redução de movimento seguem como requisitos.
- Tokens de cor do shadcn mapeados em `app/globals.css` (`@theme inline`), para que os componentes de UI herdem a paleta.
- Escalas sensoriais: pontos (●●●○○) para leitura, barras para comparação e botões de 1 a 5 na ficha de degustação.
- Mobile first: navegação inferior com cinco destinos; busca no topo.
